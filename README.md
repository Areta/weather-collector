# Weather Collector

Невеликий Python-застосунок, який отримує поточну погоду з [Open-Meteo](https://open-meteo.com/) за координатами, виводить результат у консоль і зберігає його у JSON-файл.

## Вимоги

- Python 3.10 або новіший
- Інтернет-з’єднання

API-ключ для Open-Meteo не потрібен.

## Встановлення

У PowerShell перейдіть до папки проєкту та встановіть залежності:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Створіть файл `.env` на основі `.env.example` і задайте власні значення:

```dotenv
LATITUDE=49.2333
LONGITUDE=28.4667
CITY_NAME=Vinnytsia
OUTPUT_FILE=results.json
```

`LATITUDE` і `LONGITUDE` мають бути числами. `OUTPUT_FILE` задає шлях до JSON-файлу; відносний шлях рахується від поточної папки запуску.

## Запуск

```powershell
python main.py
```

Після успішного запиту застосунок виведе запис про погоду у консоль і додасть його до масиву записів у вказаному JSON-файлі. Якщо файл ще не існує або порожній, він буде створений. Запис містить:

- `city` — назву міста;
- `temperature` — температуру в °C;
- `wind_speed` — швидкість вітру в км/год;
- `time` — час вимірювання, наданий API;
- `fetched_at` — час отримання даних у UTC.

У разі відсутніх або некоректних налаштувань, помилки API чи проблем із файлом застосунок виведе повідомлення про помилку та завершиться з ненульовим кодом.
